# FastAPI Authentication Application

A simple FastAPI web application implementing:

- User Registration
- User Login
- Welcome Page
- Logout
- Session-based Authentication
- Password Hashing using bcrypt
- SQLite Database using SQLAlchemy
- CSRF Protection for Logout

This project is designed for learning how real-world authentication systems work in FastAPI.
